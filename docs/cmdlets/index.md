# RackStack PowerShell module — Cmdlet reference

The RackStack PowerShell module is a thin wrapper around `RackStack.exe`.
After `Install-Module RackStack` and installing the EXE (via the bootstrap
script, the MSI, or by setting `$env:RACKSTACK_EXE`), the following
cmdlets become available:

| Cmdlet | What it does |
| ------ | ------------ |
| [`Get-RackStackExePath`](Get-RackStackExePath.md) | Locate the installed `RackStack.exe`. |
| [`Test-RackStackInstalled`](Test-RackStackInstalled.md) | Return `$true` if RackStack is discoverable on this machine. |
| [`Get-RackStackVersion`](Get-RackStackVersion.md) | Return the installed version (or latest published with `-Remote`). |
| [`Test-RackStackUpdate`](Test-RackStackUpdate.md) | Check whether a newer version is available. |
| [`Update-RackStack`](Update-RackStack.md) | In-place upgrade of the installed EXE. |
| [`Get-RackStackActionList`](Get-RackStackActionList.md) | Enumerate all CLI actions the installed EXE supports. |
| [`Invoke-RackStackAction`](Invoke-RackStackAction.md) | Run any CLI action and return its output (parsed when `-OutputFormat JSON`). |
| [`Invoke-RackStackSelfTest`](Invoke-RackStackSelfTest.md) | Run the internal diagnostic; returns a structured object. |
| [`Export-RackStackLogs`](Export-RackStackLogs.md) | Bundle transcripts + session state + environment into a support zip. |

## Quick examples

```powershell
# Sanity check that the EXE is installed and locatable.
if (-not (Test-RackStackInstalled)) {
    throw "RackStack.exe not found. Run Install-RackStack.ps1 first."
}

# Check for and install updates.
if ((Test-RackStackUpdate).UpdateAvailable) {
    Update-RackStack
}

# Run any CLI action as a structured cmdlet, then keep working in the pipeline.
$result = Invoke-RackStackAction SelfTest -OutputFormat JSON
$result.Checks | Where-Object { -not $_.Passed }

# Run a batch deployment headlessly from a script.
Invoke-RackStackAction Batch -Config C:\configs\hyperv-host.json -Silent -OutputFormat JSON -Stream |
    Where-Object { $_.event -eq 'step.complete' }
```

## How docs stay in sync with the module

These pages are generated by [PlatyPS](https://github.com/PowerShell/platyPS)
from the comment-based help blocks in `RackStack.psm1`. The
`Update cmdlet docs` step in CI runs `New-MarkdownHelp -Module RackStack`
on every release and publishes the result to GitHub Pages so the docs
reflect the cmdlets present in the latest PSGallery release.

To regenerate locally:

```powershell
Install-Module platyPS -Scope CurrentUser
Import-Module .\RackStack.psd1 -Force
New-MarkdownHelp -Module RackStack -OutputFolder docs\cmdlets -Force -NoMetadata
```
