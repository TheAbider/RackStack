# Support

Where to file what, depending on what you have:

## Bug report
- **Issue tracker:** https://github.com/TheAbider/RackStack/issues/new?template=bug_report.yml
- Templates ask for version, OS, PowerShell version, repro steps, and expected vs. actual behavior. Filling them in honestly is the fastest path to a fix.

## Feature request
- **Issue tracker:** https://github.com/TheAbider/RackStack/issues/new?template=feature_request.yml
- Before filing, check [ROADMAP.md](ROADMAP.md) — your idea may already be planned, or explicitly out-of-scope.

## Question / how-do-I
- **Issue tracker:** https://github.com/TheAbider/RackStack/issues/new?template=question.yml
- Before filing, scan the [README](README.md), the [cmdlet reference](https://theabider.github.io/RackStack/cmdlets/), and existing [closed issues](https://github.com/TheAbider/RackStack/issues?q=is%3Aissue) — many "how-do-I" questions are already answered.

## Security vulnerability
- **DO NOT file in the public issue tracker.**
- Use [GitHub Security Advisories (private)](https://github.com/TheAbider/RackStack/security/advisories/new) — the maintainer's notification path.
- Full disclosure policy and response timeline: [SECURITY.md](SECURITY.md).

## Paid support / commercial licensing
- Not offered. RackStack is MIT-licensed and maintained as a personal open-source project.
- If you need an SLA, fork the repo and deploy a maintained copy in your environment per the MIT license terms.

## Response expectations

| Channel | Response target |
|---|---|
| Security advisory (private) | Acknowledgement ≤ 5 business days, Tier 1 fix ≤ 14 days |
| Bug report (public issue) | Triage ≤ 10 business days |
| Feature request | Read and labeled; implementation is at maintainer's discretion |
| Question | Best-effort; not guaranteed |

The project is single-maintainer (see [GOVERNANCE.md](GOVERNANCE.md)). Response times are best-effort; if a critical issue is languishing, a bumped-priority comment on the issue is welcome.
